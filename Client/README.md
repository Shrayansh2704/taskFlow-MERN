# TaskFlow Client

This directory contains the frontend of the TaskFlow application.

## Tech Stack

- React
- Vite
- Tailwind CSS
- React Router DOM
- Axios
- React Hot Toast
- React Icons

## Features

- User Authentication
- Dashboard
- Todo Management
- Profile Management
- Password Reset
- Email Verification
- Responsive User Interface

## Installation

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```

## Environment Variables

Create a `.env` file.

Example:

```env
VITE_API_URL=
VITE_CLOUDINARY_CLOUD_NAME=
VITE_UPLOAD_PRESET=
```
